# 🎵 SUNIIYO - Professional Music Website

## Overview

A modern, professional music artist website built with HTML, CSS, and JavaScript. Features a Spotify-style dark theme with smooth animations and responsive design.

## 🎨 Features

✅ **Professional Design** - Dark theme inspired by Spotify and Apple Music
✅ **Responsive Layout** - Works seamlessly on desktop, tablet, and mobile
✅ **Music Player Integration** - Embedded Spotify player
✅ **Albums Gallery** - Showcase your music releases
✅ **Social Media Links** - Connect with fans on Instagram, YouTube, Telegram, and Spotify
✅ **Contact Form** - Direct messaging capability
✅ **Smooth Animations** - Beautiful transitions and hover effects
✅ **SEO Friendly** - Optimized for search engines

## 🔧 Customization

To customize this website for your own music:

1. **Update Artist Information:**
   - Replace "Suniiyo" with your name
   - Update bio text
   - Change social media links
   - Update contact information

2. **Add Your Music:**
   - Replace Spotify embed link with your artist profile
   - Update album titles and descriptions
   - Add track information

3. **Customize Colors:**
   - Modify CSS variables in `style.css`
   - Change primary color, backgrounds, etc.

4. **Add Your Photos:**
   - Replace album cover placeholders
   - Add artist photos in about section
